BenchMesh APT repository

BenchMesh for Ubuntu 22.04 and later, Debian 12 and later and Raspberry Pi OS (64-bit), amd64 and arm64. Installing the package from benchmesh.online adds this repository too.

sudo install -d /usr/share/keyrings
curl -fsSL https://apt.benchmesh.online/benchmesh-archive-keyring.gpg | sudo tee /usr/share/keyrings/benchmesh-archive-keyring.gpg > /dev/null
sudo curl -fsSL -o /etc/apt/sources.list.d/benchmesh.sources https://apt.benchmesh.online/benchmesh.sources
sudo apt update && sudo apt install benchmesh

Versions: 0.1.34, 0.1.33, 0.1.32
